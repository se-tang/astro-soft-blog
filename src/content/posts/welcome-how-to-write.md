## 如何发布一篇新文章？

你只需要在 `src/content/posts/` 文件夹里新建一个 `.md` 文件（例如 `my-first-note.md`），并在文件最顶部加上一段这样的信息：

```markdown
---
title: "你的文章标题"
description: "一句话介绍这篇文章讲了什么"
pubDate: 2026-11-17
category: "随笔"
tags: ["生活", "记录"]
---

这里开始写你的正文内容……
```

> 提示：只要保存文件，网站就会自动把新文章排在首页列表里，并生成对应的分类标签和 RSS 订阅。

## 常用 Markdown 排版示例

| 语法 | 效果 | 适用场景 |
| :--- | :--- | :--- |
| `## 标题` | 二级小标题 | 划分文章段落 |
| `**加粗**` | **加粗文字** | 强调重点 |
| `> 引用` | 左侧带竖线的提示块 | 引用名言或注意事项 |
| `` `代码` `` | `行内代码` | 标注文件名或命令 |
